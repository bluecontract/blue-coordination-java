The next draft uses one cause-bound participant rule for both C-first and
B-first selection. For a pending return occurrence, participants are its actual
return path minus the immutable source SCC. A participant may process only its
still-selected original LIVE cause at the exact boundary, never later work.
For a registered row the owning barrier supplies the cause. For a root-local row,
actual retained terminal records and their original-view chain supply it; lack
of such proof preserves the ordinary fence. A borrowed row does not create a
plan: terminal reconciliation requires the independently published consumer's
matching real row, plan, barrier and canonical terminal work. This lets B-first
expose C's original input for real plan creation, while C-first exposes B's
original input. A local terminal waits when that independent work is unavailable.

A blocked receiver is not automatically unfinished forever: positive evidence
of no earlier/same-boundary local or registered work plus an unfenced next LIVE
strictly *after* the boundary (or no next input) proves its prefix is complete.
That inspection does not execute the later input. Conversely, unknown, missing,
or blocked earlier work remains a prerequisite. Point and global fairness both
record the actual calculating local root rather than the registered consumer.

The first four-node draft used D→C, B→D, A→B, two A tokens to C with `next=B`
and `next=D`, one eventless later A step, then C→A. Its proposed A0/B1/D1/C2
oracle was incorrect for the template's direct-member channel, as explained
below; it did not establish two authored receiving obligations.
The original C-first/B-first witness tests now preserve their

maintained global selector. All original token/counter/history/edge/READY and

each actual retained entry-owner set, not the root last passed to an unrelated
test helper. Manual terminal inspection reads real canonical work directly,
without pretending the intentionally blocked C root was selected.
