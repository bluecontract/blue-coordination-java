# Late cyclic joins and source-owned prerequisites

A saved-original attachment can close a cycle while an independently admitted
source still has causal work before the attachment boundary. Freezing that
incomplete source view can later attempt to publish a calculated descendant over
its newer independent state. The publication fence must reject that mismatch.

Before freezing a possible cyclic join, the adapter now reads authenticated
pre-boundary forward views and checks for earlier source-owned work. Pending
history is bound to its occurrence, activation generation, exact cursor, plan and
barrier. A missing selectable work item is not evidence of completion. Existing
root-local pending history also prevents freezing the incomplete source view.
The result is a typed resource prerequisite; it publishes no source state,
receipt, occurrence or catch-up cursor. Real source work remains a separate,
ordinarily metered public processing selection.

Authenticated newly authored children retain the existing prospective-birth path.
The exemption follows managed birth declaration authentication, including retained
root-local birth provenance. It is not inferred from an authored reference alone.
No gas, original history or final publication check is relaxed.

The saved-original A→B→C→A regression first checks the root-only wait leaves all
heads and histories unchanged. The public journal driver then owns the actual
prerequisite selections and final attachment within the original 32-selection
bound. A second scenario explicitly executes the two exact prerequisites; a third
restarts while blocked and verifies the same prerequisite. Figure-eight, finite
source events, immutable history prefixes and restart checks remain independent.

A fully formed ring owns all three documents, so it is not an unowned-child
reference-rebinding proof scenario. RootedReadOnlyReferenceRebindTest requires two
actual same-epoch parent rewrites over an independently owned child. Each must
pass the existing authenticated proof and reject empty, wrong, extra, duplicated,
wrong-owner and foreign-result evidence. This test passed before that proof owner
was moved from the ring test; no proof predicate or negative was removed.

The previously proposed future-head conflict is not a new runtime rule. A genuine
A500/C300 schedule is already rejected by timeline completeness at append, with
unchanged journal and histories before and after restart. Another negative makes
earlier retained history genuinely unavailable and verifies the join stays blocked.

These are development regression owners. Final source limits, library gates,
all production obligations and complete packaged MyOS acceptance remain required.
